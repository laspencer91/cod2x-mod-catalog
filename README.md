# CoD2x Mod Catalog

This catalog lists public GitHub release repositories that the [CoD2x Launcher](https://github.com/laspencer91/cod2x-launcher) can browse.

Publish mod.zip and mod.json on a versioned release in your mod’s repository. Submit a [listing request](https://github.com/laspencer91/cod2x-mod-catalog/issues/new?template=publisher-request.yml) once. Later releases come directly from the approved mod repo.

The launcher’s [publishing guide](https://github.com/laspencer91/cod2x-launcher/blob/main/docs/publishing.md) describes the package format.
