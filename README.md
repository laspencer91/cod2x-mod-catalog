# CoD2x Mod Catalog

This catalog lists public GitHub release repositories that the [CoD2x Launcher](https://github.com/laspencer91/cod2x-launcher) can browse.

Publish `mod.zip` and `mod.json` on a versioned release in your mod’s repository, then submit the [listing form](https://github.com/laspencer91/cod2x-mod-catalog/issues/new?template=publisher-request.yml). GitHub checks the release and opens a pull request adding your mod ID and repository to `catalog.json`. Follow the link posted on your request to see its review status.

A catalog maintainer reviews the publisher, release, and proposed entry. One approval lets GitHub merge the change and close the request. Players see the listing when their launcher refreshes. Future releases from the same repository appear automatically.

The launcher’s [publishing guide](https://github.com/laspencer91/cod2x-launcher/blob/main/docs/publishing.md) describes the package format.
